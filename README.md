# herdr-shepherd-layout

The **Shepherd** layout for the Herdr app: every agent and terminal of every space in one list, with a command line. See [shepherd/RECIPE.md](shepherd/RECIPE.md).

To install, copy `shepherd/layouts/*` into `~/.config/herdr-app/layouts/` and `shepherd/mods/shepherd` into `~/.config/herdr-app/mods/`, then add `"layout:shepherd": { "escape": "shepherd.escape" }` to `keys.json`.
